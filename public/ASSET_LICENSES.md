## Source/runtime separation

Source ZIPs, original GLBs and source license files are retained outside runtime. Runtime GLBs embed source texture palettes, so they are self-contained. The operator keeps all 24 animation clips. The source names identify assets in this document; fictional game weapon/operator names are separate.

## Scope limits

These are intentionally low polygon source models. Buildings are primarily exterior models; enterable hero-building interiors must be implemented separately. Models have one source LOD and require runtime instancing/distance culling. No downloaded copyrighted game assets, brands, sounds, music, logos or UI are included.

Exact download URLs, hashes and byte sizes are recorded in `assets/additional-manifest.json` (download provenance) and `assets/runtime-report.json` (processed output). Original pine source is retained separately as `assets/source/originals/quaternius-pine-source.glb`; the prepared runtime version remains self-contained, with three embedded PNG textures and 1,646 triangles.

Texture integration: color/diffuse uses sRGB; normal and roughness maps stay linear. Use RepeatWrapping. Concrete physical repeat width: 1.8 m. Rusty metal physical repeat width: 2.2 m. All JPEGs verified at 1024 x 1024. Start normalScale around .35 to .65 to avoid exaggerated surface noise at gameplay distances.

Foliage integration: normalize loaded pine to desired world height via Box3 while retaining nested source transforms. Instancing and distance culling are appropriate; leaves already use MASK with cutoff .45, doubleSided=true, transparent=false through GLTFLoader. The model is detailed stylized foliage, not photogrammetry. It has better branch silhouette than the initial Kenney pines without requiring a large photogrammetry model download.

If retaining Kenney pines, replace the `leafs*` material color with a restrained dark evergreen such as `#263f2b` and `woodBark*` with `#4b4030`; set metalness=0 and roughness=.9. Clone shared materials only when per-instance tint variation is intended. Existing cyan is the source palette, not a renderer lighting failure.

## Runtime pipeline modifications

All GLBs receive deduplication, pruning, animation resampling and Meshopt compression. Nature and industrial models also have separately generated simplified LODs. Procedural buildings use world-aligned PBR UVs. Foliage is tinted to a darker coastal palette. Original authored map architecture, VTOL geometry, legacy procedural gloves/sleeves, UI, Web Audio synthesis and visual effects are project-created. The promotional image was generated with OpenAI ImageGen.

## Scoped rifle and optical attachment upgrade

- **WA2000 by ExodeCode**, [creator source](https://exode.itch.io/wa2000), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Used in `weapons-real/wa2000.glb` and its rendered `wa2000.png` preview. Converted the authored FBX and PBR maps to GLB, normalized scale/orientation, separated scope/magazine/lens components, added optical and grip markers, resized maps to 1K and compressed color/packed maps. The authored scope is included in the original rifle.
- **Scoped Hunting Rifle** uses [Hunting Rifle by Lucian Pavel](https://opengameart.org/content/hunting-rifle) and [Rifle Scope by LonesomeDucky](https://opengameart.org/content/rifle-scope), both [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Used in `weapons-real/scoped-hunting.glb` and `scoped-hunting.png`. This is a scoped configuration of the existing rifle, not a different rifle model. Original meshes and textures are retained; project-authored clamp rings/stems fit the scope to the receiver. The original lens cap faces were separated and optical markers measured.
- Optional rifle **MountedOptic** attachments are runtime clones of the `Scope` group from `weapons-real/scoped-hunting.glb`; their scope artwork therefore has the same LonesomeDucky CC0 provenance and project-authored mount adaptations. There is no additional standalone scope asset file.
